# HTML Cleaner and Splitter

## Описание

Этот инструмент командной строки на Go предназначен для обработки HTML файлов. Он может выполнять следующие действия:

* **Очистка кода:** Удаление нежелательного содержимого, такого как base64 URL, длинные base64 строки, комментарии, data-savepage атрибуты и скрипты, а также пустые теги `<style>`.
* **Разделение контента:** Извлечение стилей из тегов `<style>` в отдельный CSS файл и скриптов из тегов `<script>` (без `src`) в отдельный JS файл. Ссылки на эти файлы автоматически добавляются в HTML.
* **Удаление неиспользуемого CSS:**  В дополнение к разделению, инструмент может анализировать HTML и удалять неиспользуемые CSS правила для уменьшения размера CSS файла. (Точность удаления ограничена, некоторые динамические селекторы могут быть пропущены).
* **Все действия:** Выполнение всех вышеперечисленных действий за один запуск.

Инструмент предоставляет гибкость в обработке HTML файлов, делая их чище, структурированнее и потенциально оптимизированнее для загрузки.
